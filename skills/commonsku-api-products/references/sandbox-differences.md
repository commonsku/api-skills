# Products in sandbox

Sandbox matches production for the `product` and `products` tags.

Both specs list `GET /products`, `POST /products`, `GET /products/{id}`, `PUT /products/{id}` and `GET /product/search` with the same parameters, request bodies, responses and Beta Feature label. The sandbox spec can change before production, especially for newly released operations. When working in sandbox, read the sandbox spec; the `commonsku-api-setup` skill gives its address.
